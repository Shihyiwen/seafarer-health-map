# 船員醫療事件編碼 Skill

## 用途
1. **事件編碼**：把一份或多份船上醫療報告轉成 `events.csv` 相容的 JSON 列。
2. **行前健康風險提示**：輸入航次計畫（裝卸港與預計航路），輸出沿途風險與準備事項。

## 步驟一：去識別化（一定先做）
- 刪除：姓名、護照／船員證號碼、電話、Email、住址、出生日期。
- 精確年齡改為年齡帶（20-29、30-39…）。
- 職稱保留到職務類別：甲板幹部、甲板普通船員、輪機幹部、輪機普通船員、廚務。
- 在 `pii_removed` 列出刪除了哪些類型，不要寫出原值。

## 步驟二：疾病類別（擇一主要類別）
| key | 類別 | ICD-10 章節 |
|---|---|---|
| MSK | 肌肉骨骼 | M00–M99 |
| INJ | 外傷 | S00–T98 |
| SKN | 皮膚 | L00–L99 |
| GI | 腸胃／腹部 | K20–K93, R10 |
| RSP | 呼吸道 | J00–J99 |
| DEN | 牙科 | K00–K14 |
| CVD | 心血管 | I00–I99 |
| PSY | 精神／心理 | F00–F99 |
| URO | 泌尿 | N00–N99 |
| INF | 感染／發燒 | A00–B99, R50 |
| EYE | 眼科 | H00–H59 |

無法判斷時選最接近者，並在 `rationale` 說明不確定之處。

## 步驟三：嚴重度
- **1 輕微**：船上依醫療指南即可處置，不影響或短暫影響工作。
- **2 中度**：需 TMAS 遠距諮詢或持續觀察，暫時不能執勤。
- **3 重度**：需在下一港或合理時間內岸上就醫（如疑似骨折、牙齒膿瘍、持續高燒）。
- **4 危急**：可能危及生命或肢體，需立即偏航或後送（如胸痛疑似急性冠心症、大量出血、意識改變、急腹症）。
- 有疑慮時取較高等級，並標記 `needs_review: true`，交由職業衛生護理人員覆核。

## 步驟四：位置與外部風險
- 把報告中的船位（度分）換算成十進位 `lat`、`lon`；在港內則 `at_sea: 0`。
- 若船位在 JWC 戰爭風險列名區域（以最新 JWLA 通告為準），填 `war_listed_area` 區域名稱，並提醒：P&I 標準條款排除戰爭風險、進入前需通知保險人；送醫港口優先考慮列名區域外港口。
- 若事件為感染／發燒且近 14 日內停靠瘧疾或黃熱病風險港口，在 `alerts` 註明，提示 TMAS 醫師。

## 輸出格式（每件事件一列 JSON）
```json
{"date":"YYYY-MM-DD","vessel":"","rank":"","age_band":"","cat":"","icd10":"",
 "severity":1,"rationale":"","lat":0,"lon":0,"at_sea":1,"action":"",
 "war_listed_area":"","alerts":[],"needs_review":false,"pii_removed":[]}
```

## 行前健康風險提示（航次計畫模式）
輸出一張表：航段 → 最長送醫航時、是否經過列名區域、沿途傳染病風險港口（瘧疾／黃熱病／登革熱）、建議措施（黃熱病疫苗國際證明、瘧疾預防用藥評估、防蚊、醫藥箱補充、指定後送港口）。風險資料一律註明來源與查詢日期。

## 限制
- 本 Skill 協助管理與統計，不做診斷，不取代 TMAS 醫師判斷。
- 真實醫療報告只能在公司授權的環境處理，不可上傳到公開網站或未經核准的 AI 服務。
